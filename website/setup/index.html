01

Give your library
a home.

Download Suwayomi’s bundle for your computer from its official release page. The Windows ZIP and macOS bundles include Java, so you don’t have to install Java separately for those packages. Linux package requirements vary; follow its official instructions.

Start with the Windows ZIP steps below, or follow the official instructions for your operating system. Keep Suwayomi running whenever you read in your browser.

Download SuwayomiOfficial instructions
  1. On the release page, expand Assets and choose the file ending in windows-x64.zip. For example: Suwayomi-Server-v2.4.2366-windows-x64.zip. These steps use the ZIP, not the MSI installer or standalone JAR.
  2. In Downloads, right-click the ZIP and choose Extract All. Keep the extracted folder somewhere permanent. Open it; if it contains another folder with the same name, open that too.
  3. Open Suwayomi Launcher.bat (shown as “Suwayomi Launcher” with type “Windows Batch File” when extensions are hidden). The similarly named JAR is not the bundled Windows launcher.
  4. In the launcher, choose Launch. Wait for Suwayomi’s library to appear in your browser. First startup can take a few minutes and download additional components.
Windows shows a publisher warning.

Pause and check that you downloaded from the official Suwayomi release linked above. The release page also provides Checksums.sha256 for verification. Only choose Run if you trust that download. If Windows blocks it or you are unsure, stop and use the official support instructions. Do not disable Windows protection.

Already have a Suwayomi library?

Back it up before upgrading or changing its interface. For a separate library, create an empty folder first, then use the launcher’s Root Directory → folder button to select that exact folder before Launch. Keep a note of the selected path. Selecting Downloads itself puts library files directly in Downloads. Recheck settings after changing the root directory.

Using macOS, Linux, or a different Windows package?

Windows offers both windows-x64.zip and an .msi installer. Use the ZIP for the steps above; the installer has its own installation flow. For a Mac, choose macOS-arm64 for Apple silicon or macOS-x64 for Intel. For Linux, follow Suwayomi’s official Linux instructions. Prefer an operating-system bundle to the standalone .jar when you want the included runtime.

Release filenames may change. The official instructions are the source of truth.

02

Make room
for Yomikura.

In Suwayomi’s own web interface, open More → Settings → WebUI → Flavor and choose Custom.

Before stopping, if you will only read on this computer, open More → Settings → Server → IP, enter 127.0.0.1 and save. Restarting applies this local-only setting. Keep any existing remote-server protections if someone else manages your library.

Then stop Suwayomi’s server: open its icon beside the Windows clock (it may be under the hidden-icons arrow), open its menu and choose Quit. Closing the browser tab does not stop the server. If the tray icon is unavailable, follow Suwayomi’s official shutdown instructions before changing files. Choosing Custom first tells Suwayomi to use the files you provide, rather than replace them with its default interface.

This is a setting in standalone Suwayomi, not in Yomikura Desktop. You don’t need these steps for the recommended desktop installation.

03

Bring in
your reading room.

Download the prebuilt Yomikura web package. There’s no source code to build.

Download web filesChecksum

Yomikura v1.0.25-beta.5 · browser files only

  1. Open Suwayomi’s data folder. Find the folder named webUI.
  2. Keep a recovery copy: rename that folder to webUI-original. If that name already exists, choose a different backup name.
  3. Create a new folder named webUI. Extract the Yomikura ZIP and put its contents inside it.

index.html belongs directly inside webUI, alongside assets. Leave your database, downloads, extensions and other library folders alone.

Where is Suwayomi’s data folder?

First check the launcher’s Root Directory. If you selected a custom folder, use that exact folder. The usual locations below apply when no custom root is selected. The right data folder contains server.conf and webUI; it is not the extracted application folder with jre, electron and bin. If multiple libraries exist, confirm which one you started before renaming anything.

Windows%LOCALAPPDATA%\Tachidesk

Paste the Windows location into File Explorer’s address bar.

macOS~/Library/Application Support/Tachidesk

In Finder, choose Go → Go to Folder and paste the location.

Linux~/.local/share/Tachidesk

04

Open the door.
Pick a story.

Reopen Suwayomi Launcher.bat, confirm the same Root Directory and choose Launch. Open the same library address you used before. You should now see Yomikura.

For a server on this computer using its usual settings, the address is http://127.0.0.1:4567. If you chose another address or port, use that instead.

Opens the address directly in a new tab. No library address is sent to Yomikura’s website.

If Yomikura asks to connect, choose Connect an existing library and use that same address.

Then open Discover → Extensions → Stores. Add a store you trust, review its publisher, install a source and find your first comic. Nothing from a third-party source is bundled.

A little help, if you need it

Something
not quite right?

I still see Suwayomi’s old interface.+

Confirm the Flavor setting was saved as Custom, the server was stopped while you replaced files, and index.html sits directly inside the persistent webUI folder. Close old library tabs and open the address again. A normal hard refresh (Ctrl+Shift+R on Windows/Linux, Cmd+Shift+R on a Mac) can refresh an old cached page.

Yomikura says an app update is ready.+

This browser already has an older Yomikura interface open. Finish reading, close every Yomikura tab and any installed Yomikura browser window for this address, then reopen your library. A reload alone may keep the earlier version while another tab is using it. Do not clear site data: it can remove local preferences and saved records.

The library address doesn’t open.+

Check that Suwayomi is running. Use its actual address, including any custom port. Localhost means the device you’re using; on another device, use the address of the computer running the server. That computer must stay on and reachable.

How do I return to the old interface?+

Stop Suwayomi. Move the Yomikura webUI folder aside, then restore your saved webUI-original folder as webUI. Restart the server. In the restored interface, change Flavor back to the default WebUI. Your database and chapter downloads were never part of this folder replacement.

Can I connect straight from the public demo?+

The public demo uses original sample stories. For your personal library, the local setup above serves Yomikura and Suwayomi together. This avoids a public HTTPS page trying to contact a separate HTTP local server. You don’t need to change browser security settings.

Which server versions have been tested?+

The prebuilt web interface has been tested on Suwayomi v2.3.2243 and v2.4.2366: connecting, browsing the built-in Local source, adding a book, reading, saving progress and refreshing deep links. This does not verify every extension or signed-in tracker. Desktop managed setup remains pinned to v2.3.2243. Keep a library backup before changing server versions.

I already use a custom subpath or a hosted server.+

This web package expects the standard root web-interface location. Custom subpaths, authentication and remote hosting may need your administrator’s configuration. Follow Suwayomi’s official settings and preserve your existing server protections.
