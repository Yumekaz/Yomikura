Before you settle in

A few things
you might wonder.

Is Yomikura free?+

Yes. Yomikura is free and open source. There’s no Yomikura account or subscription, and you can browse the source on GitHub.

Does it come with comics?+

The demo includes two original illustrated samples. For your own reading, you choose and configure your sources through Suwayomi. Yomikura is a reader, not a hosted comic catalogue, and includes no third-party extensions.

Do I need to know how to code?+

Not for the desktop app. Download the installer, open Yomikura and choose Set up my library. It prepares Java and Suwayomi when needed. Browser setup takes a few more steps; the illustrated guide explains each one without asking you to clone the code.

What is Suwayomi?+

Suwayomi keeps your library, manages sources and fetches chapters. Yomikura is the interface you use to organize and read them. The desktop app can manage a local Suwayomi library for you; browser users run Suwayomi separately.

Can I keep reading offline?+

On desktop, chapters saved on your device remain readable even if your library server is unavailable, and pending progress is retained for reconnection. Server-downloaded chapters can also be read while that server remains reachable. Unsaved pages still need a working connection to their source.

Where do my books and reading data live?+

Library data and server downloads live with your Suwayomi server. Yomikura keeps preferences and retained device data locally. Back up your library before changing installations. The privacy page explains the details.

What should I know before installing?+

Windows releases receive installer and automated browser checks. Interactive macOS/Linux testing, physical pinch hardware and signed-in tracking providers have separate coverage limits. Platform signing is not yet configured. Read the release notes before installing.
