# Original demo stories

Moonlit Courier and The Paper Garden are fictional illustrated samples created for Yomikura's visual redesign. Their covers and wordless interior pages were generated with the built-in ImageGen tool on 2026-10-24, using original scene and character descriptions. Each interior page used its story's generated cover as a style reference.

No existing comic, franchise, publisher artwork or external photo is represented by these samples. The visible “A Yomikura Original” line identifies this project's demo artwork; it is not a publisher credit or a claim about a user's library.

The consumed files are WebP derivatives: 640×960 covers and 768×1152 sample pages. Untouched 1024×1536 PNG originals, exact generation prompts and visual evidence are retained in the local task evidence folder. Only these deliberately included derivatives ship with the app.

Demo records retain a separate demo identity. Original artwork must never replace real source thumbnails, manga metadata or a user's content.
