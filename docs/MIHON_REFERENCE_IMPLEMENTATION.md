# Screenshot-guided Mihon parity review

This reconciles all 50 individually reviewed private references against the current implementation. The reference images, names, fingerprints, raw notes, APK and local evidence remain private. Implemented means the described behavior exists in source and targeted checks; adapted identifies a desktop/web equivalent or a concrete backend boundary. It does not mean all Mihon features or every provider/hardware scenario have been validated.

Pinned evidence: Mihon v0.21.2 at `9612d955db3165e1578fdf9ff19ca9b7762c4a46`; Suwayomi v2.3.2243 at `1d583ca4a718646e17a4c62d23fe8e5edccaf774`. REA/JADX inspected the official Mihon APK with SHA-256 `dcfe07027cb000fac92f10303e4bc98feca3e6a4aeb026aaafce8fbe9e5c423f`. This was static analysis, not Android runtime/ADB testing.

## Source evidence and constraints

Mihon’s `LibraryPreferences.kt`, `ReaderViewModel.kt`, `ReleaseSchedule.kt`, `FetchInterval.kt`, `UpcomingViewModel.kt`, `GetUpcomingManga.kt`, `StatsViewModel.kt`, `ImageUtil.kt` and `TallImageSplitCalculator.kt` establish the compared behavior. REA verified compiled library/notes/reader paths, `ImageUtil.splitTallImage` and `Manga.getExpectedNextUpdate`. The latter suppresses an absent estimate or completed publication.

Suwayomi’s `Updater.kt`, `UpdateMutation.kt`, `CategoryMutation.kt`, `SourceMutation.kt`, `TrackMutation.kt`, `ImageMutation.kt`, `MangaType.kt` and `NetworkHelper.kt` establish the implemented API boundaries. Sources, extension execution, source networking, library data and server downloads remain owned by Suwayomi. Yomikura does not inject raw SQL or pretend a browser setting changes the engine’s networking.

Native verification uses an isolated application identifier and original demo-art fixture. Reading tests against the owned real engine exercised four Asura titles, two chapters per title, decoded pages, saved progress and restoration. Authentication with a real tracking provider or Windows Hello user, physical screen sleep/e-ink behavior, and other operating systems remain separate runtime limits.

Final validation is recorded in [MIHON_PARITY_PROGRESS.md](MIHON_PARITY_PROGRESS.md). Earlier failed attempts remain preserved privately.
