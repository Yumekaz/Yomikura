# Yomikura v1.0.25

This release combines the beta.5 reading experience with the subsequent public security and packaging repairs. Its source retains the reading-room identity, library isolation, automatic saved reading, chapter endings, shared zoom, working source links, extension notices, comic-level history, duplicate review and visual browser setup guide.

## Install and update

Download from the [official release](https://github.com/Yumekaz/Yomikura/releases/tag/v1.0.25). Windows x64 is the tested desktop path. Apple-silicon macOS and Linux x86_64 packages have separate runtime coverage limits. Publisher signing/notarization remain unavailable; updater payload signatures provide separate integrity verification.

Before updating, retain a backup and your existing library folder. Close the app, install the update over the existing application and keep the data folder. New desktop readers choose **Set up my library**; guided setup downloads the verified Java and Suwayomi components when needed. No sources or third-party comic content are bundled.

Browser readers can use the [public visual guide](https://yumekaz.github.io/Yomikura/setup/) and prebuilt web download without cloning the repository. Keep a recovery copy of an existing Custom WebUI before replacing interface files.

## Security and reliability

- Updates affected native ZIP/TLS/transport and updater dependencies, plus JavaScript build/test dependencies. Matching JavaScript/native Tauri versions are verified for packaging.
- Includes complete runtime JavaScript/UI/font license notices in future web/native builds and retains the public policy corrections.
- Preserves the latest beta's reader, download, backup and library-identity safeguards. This is a new build, not a relabelled beta.5 installer.
- Leaves the documented Linux glib dependency advisory and reviewed medium CLI build/test I/O warnings open. See [known issues](../KNOWN_ISSUES.md) and [public review](../PUBLIC_REVIEW_2026-11-04.md).

## Publication gates

Publication requires a successful tagged verification run, Windows lifecycle/private-runtime checks, all three platform package builds, verification of the exact uploaded Windows installer, and original-build checksum/updater-signature verification. The public release notes link the completed run and exact source revision. A draft or an earlier run is not evidence that these gates passed for this release.

Windows installer checks run on GitHub. Interactive macOS/Linux use, physical touch hardware, spoken screen-reader output and signed-in tracking providers retain separate limits. A stable release label does not remove those limits or guarantee third-party source availability.
