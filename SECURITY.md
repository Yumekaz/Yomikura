# Security policy

Please do not report security vulnerabilities in public issues.

For a private report, contact the maintainer through the GitHub repository profile or open a private GitHub Security Advisory when that feature is enabled for the repository. Include a short reproduction, affected version or commit, platform, and impact. Remove tokens, passwords, private server URLs, and personal data from the report.

Yomikura is a client. It does not operate a content service or central telemetry backend. Security reports may involve the Yomikura UI/native shell, the optional local backend lifecycle, or the boundary between the client and a user-configured Suwayomi server. Third-party extension, repository, and source vulnerabilities should also be reported to their maintainers.

Supported releases receive priority. Please allow reasonable time for investigation and coordinated disclosure before publishing details.
